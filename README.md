# Actividad: Aplicación Web con Vue y Firebase (Parte 2)

## Descripción y Temática
**Temática de la aplicación:** Panel de control (Dashboard) corporativo y de gestión de registros en tiempo real.
**Descripción:** Aplicación web desarrollada con **Vue 3 (Composition API)** y **Vite**, estructurada en un diseño responsive que integra un formulario de entrada de datos y un panel interactivo conectado en vivo con **Cloud Firestore**.

---

## Enlace a la Web Publicada
La aplicación se encuentra desplegada y accesible públicamente en Firebase Hosting:
**URL de Producción:** https://marenostrum-rania-web-2026.web.app
